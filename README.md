# MiniCommerce

A full-stack e-commerce application built with Next.js and TypeScript.

MiniCommerce is a portfolio project focused on learning and implementing
modern web development practices, including authentication, product
management, database integration, and role-based access control.

## Features

### Authentication and Authorization

- User registration and login
- Credential-based authentication with Auth.js
- Role-based access control for admin and regular users
- Protected admin routes

### Product Management

- Product listing and details
- Search and category filtering
- Sorting and pagination
- Admin product management
- Create, update, and delete products

### User Interface

- Responsive design
- Light and dark themes
- Form validation
- Modern UI components

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Auth.js (NextAuth.js)
- Prisma ORM
- PostgreSQL
- React Hook Form
- Zustand
- Tailwind CSS
- shadcn/ui

## Getting Started

### Prerequisites

- Node.js
- pnpm
- Docker (for the local PostgreSQL database)

### Installation

Clone the repository:

```bash
git clone https://github.com/ImanPlus/mini-commerce.git
cd mini-commerce
```
